# Math Tools

A simple teacher-facing website for whole-class math fluency and number sense routines.

## Included tools
- Quick Images: dots, ten frames, double ten frames
- Addition & Subtraction: mixed facts, Make 10, doubles, near doubles, 9 facts
- Multiplication & Division: selectable fact families, equation facts, division, mixed practice, arrays

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**.
4. Save.
5. GitHub will provide the public site URL.
